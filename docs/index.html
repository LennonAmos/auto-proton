Auto-Proton

Selects an installed Proton version for each Steam game using recent ProtonDB reports. Native Linux games use the native version by default.

Download for Linux Source code Release and checksums

Install or update

Requires Python 3.10 or newer and a systemd user session. Download the archive, then run:

tar -xzf auto-proton-linux.tar.gz
cd auto-proton
sh install.sh

Running the installer again updates Auto-Proton and keeps your settings. Steam may need one normal restart when installing for the first time.

Compatibility settings

  • Checks your library about every two minutes
  • Uses Proton versions already installed on your computer
  • Keeps the current setting when reports do not support a choice
  • Adds an Override Auto-Proton checkbox in Properties → Compatibility so you can select a version manually

Uninstall

~/.local/bin/auto-proton-uninstall

Removes Auto-Proton's installed files, services, preferences and cache. Steam's current compatibility settings stay in place.
